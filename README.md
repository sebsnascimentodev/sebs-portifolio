# sebastian_portifolio

Portfólio single-page, desenvolvido para apresentar perfil profissional, experiências, competências técnicas e formas de contato em um visual dark-tech, moderno e direto.

O projeto foi pensado para reforçar uma imagem sênior, com foco em backend, arquitetura de software, integração de sistemas e entrega de plataformas confiáveis. A composição mistura linguagem terminal, tipografia forte e elementos visuais sutis para transmitir precisão técnica sem perder personalidade.

## O que o portfólio apresenta

- Hero principal com nome, função, bio curta, status de disponibilidade e foto de perfil.
- Faixa de estatísticas com resumo de experiência, projetos e times mentorados.
- Letreiro animado com stack e ferramentas relevantes.
- Seção de skills com categorias técnicas organizadas em cards.
- Seção de projetos selecionados com cards visuais e tags de tecnologia.
- Linha do tempo profissional com experiências mais recentes.
- Área de contato com email, telefone, LinkedIn e links úteis.

## Destaques visuais

- Tema escuro com grid técnico sutil de fundo.
- Identidade inspirada em terminal e interface profissional.
- Tipografia grande, monospace para elementos técnicos e contraste forte para leitura.
- Animação de texto no hero alternando entre perfis de atuação.
- Ticker contínuo com tecnologias e ferramentas como N8N, Claude e Copilot.

## Conteúdo editável

- Nome e subtítulo principal no hero.
- Foto de perfil usada na capa.
- Biografia profissional.
- Estatísticas de carreira.
- Experiências, projetos e contatos.
- Arquivo de currículo em PDF dentro de `assets/`.

## Estrutura

- `index.html` define toda a estrutura da página.
- `styles.css` concentra o design visual e o comportamento responsivo.
- `script.js` controla a animação de texto e o ticker.
- `assets/` reúne a foto, os previews e o currículo em PDF.
